# 조사 및 구현 기록

## 조사 대상과 확인 범위

사용자 요청: Canva의 기능 구성을 참고하여 지우기, 이미지 비율 수정, 배경 제거, 확대 다운로드, PDF/JPG/PNG/SVG 변환, AI 대화 기능이 있는 앱 만들기.

- 공식 공개 주소 `https://www.canva.com/features/magic-eraser/`, `https://www.canva.com/features/background-remover/`, `https://www.canva.com/resize-image/`에 읽기 요청을 시도했습니다.
- 현재 클라우드 네트워크 프록시에서 `Tunnel connection failed: 403 Forbidden`을 받았습니다.
- 따라서 Canva 편집기 내부, 코드 구조, 모델, API, 실제 클릭 동작은 확인하지 못했습니다. 앱 기능이나 모델을 역분석했다고 주장하지 않습니다.
- REA 6.7.0의 브라우저 관찰 도구 스키마를 확인하고, 공개 Magic Eraser 페이지에 한정한 브라우저 관찰을 시도했습니다. 성공한 결과와 접근 차단을 구분해야 합니다. 브라우저는 시작됐으나 초기 페이지 이동에 실패했습니다. 관찰된 편집 화면이나 기능 동작은 없습니다. REA는 자체 시작한 브라우저를 종료했습니다. 요약 결과를 `docs/rea-canva-observation.json`에 남겼습니다.

## 독립적인 구현 결정

일반적인 편집 작업 흐름에 따라 `파일 올리기 → 도구 선택 → 이미지 수정 → 저장`으로 구성했습니다. 왼쪽 도구 목록, 중앙 미리보기, 저장 창, AI 대화 창은 이 프로젝트에서 설계했습니다. UI·일러스트·편집 코드는 독립적으로 작성했습니다.

| 질문 | 조사 결론 / 구현 |
| --- | --- |
| Canva Magic Eraser 내부 방식 | 미확인. 이 앱은 OpenCV Telea 주변 무늬 복원과 브라우저 주변색 채우기로 독립 구현 |
| Canva 비율 조절 내부 방식 | 미확인. 이 앱은 Canvas 좌표 계산으로 비율 유지·중앙 자르기 구현 |
| Canva 배경 제거 모델 | 미확인. 이 앱의 AI 모드는 공개 U²-Net 경량 모델(u2netp), 단색 배경 모드는 가장자리 flood fill |
| Canva 확대 저장 모델 | 미확인. 이 앱은 브라우저 고품질 보간으로 2·4배 확대 |
| Canva 파일 변환 구조 | 미확인. 이 앱은 PDF.js, jsPDF, Canvas, 안전 처리된 SVG로 변환 |
| Canva AI 서비스 | 미확인. 이 앱은 별도 OpenAI 대화 API로 연결하며 키 없이는 비활성화 |

README에 기능의 범위와 제한을 기록했습니다. 네트워크 접근이 허용되거나 사용자가 직접 제공한 Canva 화면·패키지가 생기면 별도 조사로 검증 범위를 늘릴 수 있습니다.

## 실제 구현 검증

브라우저에서 파일 업로드, 픽셀 변화, 정확한 되돌리기·다시 실행, 배경 투명도, 비율 변경, 확대 저장, PNG/JPG/PDF/SVG 16가지 변환, PDF 페이지 선택, 모바일 화면을 검사했습니다. 실제 AI 모델을 통한 예시 이미지 배경 제거와 OpenCV 지우기도 실행했습니다. AI 대화는 키가 없어 실제 OpenAI 응답을 검증하지 못했고, 입력 검증·비밀키 보호·오류 처리·응답 전달은 모의 외부 응답으로 별도 테스트했습니다. 이를 실제 AI 답변 검증과 구분합니다.
