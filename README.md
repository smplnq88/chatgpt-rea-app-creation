# 모아 스튜디오

사진을 올리고, 지우고, 크기를 바꾸고, 원하는 파일로 저장하는 한국어 이미지 편집 앱입니다. Canva의 소스 코드를 사용하지 않은 독립적인 앱입니다.

## 다운로드해서 바로 시험하기

[최신 HTML 앱 받기](https://github.com/smplnq88/chatgpt-rea-app-creation/releases/download/moa-browser-preview/moa-studio-v2.htm)

파일을 내려받아 두 번 클릭하면 앱이 열립니다. 서버나 별도 설치 없이 작동하는 버전입니다. 지우기 도구의 **주변 환경에 맞추기**가 기본 선택되어 있습니다. 사진을 올리고 지울 부분을 칠한 뒤 **칠한 부분 지우기**를 누르세요. 이전 `preview.htm` 파일은 자동 업데이트되지 않으므로 새 파일을 내려받아야 합니다.

**주변 환경에 맞추기**는 가까운 정상 영역에서 비슷한 무늬를 찾아 복사·연결하는 방식입니다. 단순한 색 번짐보다 반복 무늬를 보존하지만, 생성형 AI처럼 새로운 풍경을 상상해 복원하지는 않습니다. 큰 물체나 불규칙한 배경에서는 결과가 자연스럽지 않을 수 있습니다. 이 작업은 브라우저의 별도 작업 스레드에서 처리하며 사진을 서버로 보내지 않습니다. 단독 파일에서는 서버 전용 AI 배경 제거와 AI 대화는 꺼져 있습니다.

HTML 재생성: `node scripts/build-preview.mjs`. 실제 HTML 기능 검사: `node scripts/test-preview.mjs`. 내려받은 파일의 기능을 검사하려면 `PREVIEW_HTML_PATH=/path/to/file.htm node scripts/test-preview.mjs`로 실행합니다.

## 먼저 사용해 보기

1. 왼쪽의 **이미지 올리기**를 누르고 사진을 선택하세요. 예시 이미지로 연습해도 됩니다.
2. 왼쪽에서 **지우기**, **배경 제거**, **비율 변경** 중 원하는 도구를 선택하세요.
3. 잘못 편집했다면 사진 위의 왼쪽 화살표로 되돌리세요.
4. 오른쪽 위 **저장하기**를 누르고 파일 형식과 크기를 고르세요.

원본 파일은 바뀌지 않습니다. 편집 중인 작업은 새로고침하면 사라지니, 완성한 이미지는 꼭 저장하세요.

## 실행 방법

개발 도구 Node.js 24 및 npm이 필요합니다. 이 클라우드 환경에는 설치되어 있습니다.

```sh
cd /workspace/chatgpt-rea-app-creation
npm ci
npm run dev
```

개발 서버는 5173번, API 서버는 3001번 포트를 사용합니다. 클라우드 외부 접속에는 플랫폼의 포트 미리보기나 별도 호스팅이 필요합니다. 로컬 주소는 외부 공개 주소가 아닙니다.

배포용 파일을 만들고 실행하려면:

```sh
npm run build
npm start
```

`npm start`는 3001번 포트에서 앱 화면과 API를 함께 제공합니다. 실행 중인 개발 서버가 있으면 먼저 종료해야 합니다. 인터넷에 공개하는 배포는 별도 작업입니다. 현재 AI API에 사용자 로그인은 없으므로, 유료 AI 키를 설정한 서버를 공개하기 전에 사용자 인증·사용량 제한을 추가해야 합니다.

## 파일 기능과 범위

| 기능 | 동작 |
| --- | --- |
| 파일 열기 | PNG, JPG/JPEG, WEBP, SVG, PDF |
| 파일 저장 | PNG, JPG, PDF, SVG |
| 파일 변환 | PNG·JPG·PDF·SVG 각각을 열고 나머지 형식으로 저장 가능 |
| 지우기 | 주변 환경에 맞추기: 가까운 정상 무늬를 찾아 복사·연결. 서버 모드에서는 OpenCV Telea로 주변 무늬를 이어 채움. 간단한 브라우저 주변색 채우기 모드도 제공. 복잡한 무늬·큰 물체는 결과가 부자연스러울 수 있음 |
| AI 배경 제거 | 로컬 U²-Net 경량 모델로 주인공 분리. 유료 키 불필요. 사진에 따라 머리카락·경계 품질은 달라짐 |
| 단색 배경 제거 | 사진 가장자리와 연결된 비슷한 색 제거, 투명도 유지. 서버 연결 없이 브라우저에서 처리 |
| 비율 변경 | 1:1, 4:5, 9:16, 16:9 및 직접 입력. 전체 보이기 또는 가운데 자르기 |
| 확대 저장 | 1배, 2배, 4배. 부드러운 보간 확대이며 AI 초해상도는 아님 |
| PDF | 여러 쪽 중 한 쪽씩 열기. 현재 한 쪽을 이미지 PDF로 저장. 문서의 텍스트·레이어 편집은 지원하지 않음 |
| SVG | 열 때 안전하지 않은 요소·외부 참조 제거. 저장 시 PNG 이미지를 SVG에 담음. 자동 벡터화는 아님 |
| 되돌리기 | 메모리 사용량에 따라 최근 1~6단계 유지 |

파일은 최대 40MB, 이미지·확대 결과는 최대 3,200만 화소입니다. SVG와 PDF를 이미지로 여는 과정에서는 원래의 글꼴·도형 구조가 유지되지 않습니다. 보호된 PDF는 지원하지 않습니다.

## AI 배경 제거와 자연스럽게 지우기 설치

현재 클라우드에는 실제 AI 모델과 이미지 처리 도구가 설치되어 있습니다. 다시 준비할 때는 다음 한 줄을 실행하세요.

```sh
bash scripts/setup-image-tools.sh
```

Python 3.12 가상 환경에 고정 버전의 rembg·ONNX Runtime·OpenCV를 설치하고 공식 U²-Net 경량 모델을 내려받아 체크섬을 검증합니다. 기본 설치 위치는 `/workspace/rea-image-tools`이며 다른 컴퓨터에서는 프로젝트의 `.cache/image-tools`를 사용합니다. `IMAGE_TOOLS_HOME`으로 위치를 바꿀 수 있습니다. 서버를 다시 시작하면 도구가 화면에 나타납니다.

**AI 배경 제거**와 **자연스럽게 지우기**는 사진을 이 앱의 서버로 보내서 처리합니다. 제3자의 AI 서비스에는 보내지 않고, 서버 파일에도 저장하지 않습니다. 서버와 통신할 수 없거나 도구를 설치하지 않은 환경에서도 **단색 배경 제거**와 **주변색 채우기**는 브라우저에서 작동합니다. 서버 이미지 처리 입력은 PNG/JPG 데이터 약 7.5MB까지 지원합니다. 사진이 너무 크면 비율 변경 도구로 크기를 줄여 주세요. AI 모델은 320×320 입력을 사용하는 경량 모델이라 전문 도구만큼 정교한 결과를 보장하지는 않습니다.

## AI에게 물어보기

AI 대화에는 별도의 OpenAI 이용 키가 필요합니다. 키가 없으면 연결 안내만 표시하고, AI 답변을 흉내 내지 않습니다.

1. `.env.example`을 `.env`로 복사하세요.
2. `.env`의 `AI_API_KEY=` 뒤에 본인의 이용 키를 입력하세요. 키를 채팅에 보내지 마세요.
3. 서버를 다시 시작하고 AI 대화창을 다시 여세요.

`OPENAI_API_KEY`도 지원합니다. 기본 모델은 `gpt-4.1-mini`이며 `OPENAI_MODEL`로 바꿀 수 있습니다. 클라우드에서는 환경 설정의 보안 입력란으로 `AI_API_KEY`를 넣을 수도 있습니다. 키는 서버에서만 사용하고 브라우저로 전달하지 않습니다. 프록시 방식 키는 `api.openai.com`을 허용 대상으로 설정해야 합니다.

질문과 대화 내용은 OpenAI로 전송됩니다. **현재 사진도 함께 보내기**를 켠 경우에만 사진을 줄여서 함께 전송합니다. 요금이 발생할 수 있습니다. AI는 편집 방법을 설명하며 도구를 대신 클릭하지 않습니다.

## 검증

```sh
npm test
npm run build
npm run test:e2e
```

마지막 명령은 `npm run dev`가 실행 중이고 Chromium이 설치되어 있을 때 사용합니다. 기본 Chromium 경로는 `/usr/bin/chromium`입니다. 다른 경로라면 `CHROMIUM_PATH`를 지정하세요. 실행 중인 앱 주소는 `TEST_BASE_URL`로 지정할 수 있습니다. 이미지 도구를 설치한 경우 실제 AI 배경 제거와 OpenCV 지우기도 검사하며, 설치하지 않은 경우에는 해당 검사를 건너뛰었다고 표시합니다. 테스트는 임시 폴더에서 파일을 만들고, 실제 브라우저에서 편집·되돌리기·확대 저장·16가지 형식 변환·PDF 쪽 선택·모바일 화면을 검사합니다.

앱은 React·TypeScript·Canvas·Vite·Express로 만들었습니다. PDF 처리는 PDF.js와 jsPDF, SVG 정리는 DOMPurify를 사용합니다. 개발용 REA 설치·연결 설정은 보존되어 있습니다. REA와 Canva는 이 앱의 실행 의존성이 아닙니다.
